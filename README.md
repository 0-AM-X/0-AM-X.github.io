# Images

Drop your images here. Suggested names (uncomment the matching line in `_config.yml` / front matter once added):

- `avatar.png` — square profile photo for the sidebar (author avatar)
- `site-logo.png` — masthead logo (optional)
- `hero.jpg` — big splash image for the home page (use with `header.overlay_image`)
- `thumb-1.jpg`, `thumb-2.jpg` — thumbnails for project cards
